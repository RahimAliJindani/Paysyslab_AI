GitHub → Vercel Deploy Flow
1

Create GitHub Repo

github.com → New repo → Private → paysyslabs-ai-website

2

Upload HTML + Config

Drag 5 HTML files + vercel.json + README.md into repo

3

Upload Assets

Logo PNG + 4 MP4 videos (each under 25MB) → commit

4

Import to Vercel

vercel.com → Add New Project → import repo → Framework: Other → Deploy

5

Live in ~30s

Vercel URL + optional custom domain ai.paysyslabs.com
